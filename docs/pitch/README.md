## แก้สไลด์ยังไง

**ไม่ได้ทำใน Canva** — เด็คเป็น HTML ในเรโป แก้แล้วสั่งสร้างใหม่ได้ ไม่ต้องจัดหน้าเองทุกครั้ง

```bash
# แก้ docs/pitch/deck/deck.html แล้ว
npm run deck        # → deck.pdf + deck-light.pdf
```

ตัวสร้างตรวจให้ทุกครั้ง: **เนื้อหาล้นหน้า** (ทั้งระดับสไลด์และกล่องข้างใน) · ภาพเสีย · ฟอนต์ไทยไม่ติด · ตัวไทยต่ำกว่า 18px — เจอแล้วขึ้น ✗ และคืน exit code ไม่เป็นศูนย์

ฟอนต์ IBM Plex Sans Thai ตัวเดียวกับแอปฝังอยู่ใน [`deck/fonts/`](deck/fonts/) แล้ว · **เปิดและสร้างใหม่ได้โดยไม่ต้องมีเน็ต**

> ⚠️ **เนื้อหาอยู่ 2 ที่ อย่าแก้ผิดที่** — ข้อความที่ฉายขึ้นจออยู่ใน `deck.html` · สคริปต์ปาก/หมายเหตุ/เกณฑ์/Q&A อยู่ใน `speaker-notes.md` · แก้ speaker-notes แล้วสไลด์ไม่เปลี่ยน
