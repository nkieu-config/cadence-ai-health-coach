## แก้สไลด์ยังไง

**ไม่ได้ทำใน Canva** — เด็คเป็น HTML ในเรโป แก้แล้วสั่งสร้างใหม่ได้

```bash
# แก้ไฟล์ใน docs/pitch/deck/ แล้ว
npm run deck        # → deck.pdf · deck-light.pdf · showcase.pdf · showcase-light.pdf · onepager.pdf
```

ตัวสร้างตรวจให้ทุกครั้ง: **เนื้อหาล้นหน้า** (ทั้งระดับสไลด์และกล่องข้างใน) · ภาพเสีย · ฟอนต์ไทยไม่ติด · ตัวไทยเล็กเกินไป (สไลด์ 18px · A4 11px) — เจอแล้วขึ้น ✗ และคืน exit code ไม่เป็นศูนย์

QR บน showcase และ onepager คือ `deck/qr-app.png` ชี้ไป production · URL เปลี่ยนให้สร้างใหม่:

```bash
swift scripts/make-qr.swift "https://personal-healthcoach.vercel.app" docs/pitch/deck/qr-app.png
```

ใช้ตัวสร้าง QR ที่มากับ macOS · **สคริปต์ถอดรหัสภาพที่เพิ่งสร้างกลับมาเทียบให้เองทุกครั้ง** ไม่ตรงจะ exit 1

ฟอนต์ IBM Plex Sans Thai ฝังอยู่ใน [`deck/fonts/`](deck/fonts/) แล้ว — **เปิดและสร้างใหม่ได้โดยไม่ต้องมีเน็ต**

## งานที่เหลือ

เรียงตาม *พังแล้วกู้ไม่ได้* ไม่ใช่เรียงตามง่าย

1. 🔴 **ทดสอบ production บนเครือข่ายอื่น** — ประกาศสั่งตรง ๆ · แอปไม่มีโหมด offline **นี่คือความเสี่ยงเดี่ยวที่ใหญ่ที่สุด** → [booth-checklist.md](booth-checklist.md#-ทดสอบเครือข่ายอื่น--ทำก่อนวันงาน-แล้วทำซ้ำหน้างาน)
2. 🔴 **อัดวิดีโอสำรอง 2–3 นาที** — ประกาศสั่งไว้ในลิสต์แผนสำรอง เป็นข้อเดียวที่เรายังขาด
3. 🔴 **เติมชื่อในช่อง `___`** — [booth-script.md](booth-script.md) (บทบาท 4 + คำถาม 8) และ [demo-script.md](demo-script.md) (คนพูด 6 + Q&A) · ประกาศย้ำ 2 รอบว่า *"สมาชิกทุกคนควรตอบคำถามเกี่ยวกับส่วนที่ตนรับผิดชอบได้"* และเป็นคะแนนเกณฑ์ 3
4. 🔴 **ก๊อป `docs/pitch/` ลง USB + เครื่องที่สอง** — ประกาศสั่ง
5. 🔴 **หาปลั๊กพ่วง / adapter / ป้ายตั้งโต๊ะ (ชื่อทีม · ชื่อผลงาน · Mission)** — ซื้อเช้าวันงานไม่ทัน
6. **บอกทีมเรื่องชุด** — เสื้อค่าย + กางเกงขายาวสุภาพ + รองเท้าผ้าใบ
7. **เลือกโทนสไลด์ + โทนแอป** บนโปรเจกเตอร์จริง
8. **หลัง freeze** — รัน `npm run shots` แล้ว `npm run deck` ตามทันที (สไลด์ดึงภาพจากโฟลเดอร์เดียวกัน)
9. **ซ้อม 2 แบบ** — บูธ 4:00 จับเวลา ×3 + เวที 8:00 จับเวลา + Q&A แยกอีก 5 นาที
