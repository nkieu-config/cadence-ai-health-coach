## งานที่เหลือ

รายการเต็มอยู่ท้าย [slide-content.md](slide-content.md) หัวข้อ "เช็กก่อนถือว่าเด็คเสร็จ" — ตัวใหญ่ ๆ คือ:

1. ทำ 8 หน้าใน Canva → export `deck.pdf` วางที่นี่
2. เติมชื่อ 4 คน + แบ่งคนพูดใน demo-script (ยังว่าง 4 จาก 5 องก์)
3. **ทำสไลด์สำรอง 2 หน้า** — 4 เกณฑ์รวม 38% ปิดได้เฉพาะช่วง demo สด ถ้าล่มไม่มีอะไรค้ำ
4. **ยืนยันเวลาจริงกับอาจารย์** — ตอนนี้จัดไว้ 8:00 พอดีไม่มี buffer
5. รัน `npm run shots` ซ้ำหลัง freeze ให้ภาพตรงกับของจริงวันนำเสนอ
6. ซ้อมเต็ม 2 รอบวันที่ 29 ก.ค. (checklist ซ้อม + กฎเหล็กวันจริงอยู่ท้าย demo-script)
