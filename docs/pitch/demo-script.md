### ✂️ 1. Check-in (จับเวลาสด) — **ตัดจากรอบบ่าย · ใช้ที่บูธเช้า**

> บ่ายพูดตัวเลขแทน: *"มัธยฐาน 1 นาที 26 วินาที จากการจับเวลาจริง 24 ครั้ง ช้าสุด 2 นาที 14"* บนสไลด์ 3

> ⚠️ **เปลี่ยนตั้งแต่ 24 ก.ค.** — ถ้าปาล์มบันทึกของวันนั้นไปแล้ว `/checkin` จะเปิดมาเจอ**การ์ดสรุป**ก่อน ไม่ใช่ฟอร์ม (แก้ปัญหาผู้ใช้ไม่รู้ว่าบันทึกติดหรือยัง)
> **ตอนจับเวลาให้เปิด `/checkin/edit/<วันที่วันนี้>` แทน** จะเข้าฟอร์มตรงไม่ต้องกดอะไรก่อน · หรือกด "แก้ไขบันทึกนี้" จากการ์ดสรุปก็ได้ แต่จะกินเวลาเพิ่ม 1 คลิก
> ทางที่สะอาดที่สุด: รัน `npm run refresh:demo-week` เช้าวันจริง แล้วอย่าเช็คอินด้วยบัญชีปาล์มก่อนขึ้นเวที — ฟอร์มจะเปิดมาเป็น wizard ตามปกติ

1. อยู่หน้า `/checkin` ก่อนเริ่มพูด (ดูกล่องเตือนด้านบนก่อน)
2. พูดว่า "จะกรอก check-in ของวันนี้สด ๆ ขอจับเวลา" → เริ่มจับ
3. กดตอบทีละขั้น (4 ขั้น): **กิน → นอน → เคลื่อนไหว → บริบทวัน (พลังงาน + disruptor)**
4. ชี้ให้เห็น: **คำถามเวลามื้อแรกโผล่เฉพาะเมื่อเลือกว่าได้กิน** (progressive disclosure — คำถามเสริมโผล่เฉพาะเมื่อเกี่ยว)
5. กดบันทึก → หยุดเวลา → "ใช้เวลา ~__ วินาที — มัธยฐานทีม 1:26–1:30 จากการวัดจริง 24 ครั้ง" (ตัวเลขเต็มใน qa-results.md)
6. โชว์หน้าสรุปหลังบันทึก — **ชี้ "ตื่นราว …" ที่ระบบคำนวณให้เอง ไม่ได้ถามซ้ำ** (Low Burden)

### 2. Dashboard — **อยู่ในบท · งบ 45 วิ** · Plan B = **สไลด์ 11 (สำรอง A)**
1. ไป `/dashboard` — **เปิดมาค้างที่ 14 วันเลย ไม่ต้องไล่ 7 → 14 → 30** (ตัดออกเพื่อประหยัด 20 วิ)
2. ชี้ **disruptor overlay** บนกราฟ — **สีปะการังสีเดียวทุกชนิด แยกชนิดด้วยไอคอน** (เดดไลน์/เรียนเช้า/สอบ) วางบนแกนวัน
3. เล่า pattern ที่ตาเห็น: "วันนอนน้อยทับกับวันข้ามมื้อเช้าและดื่มเครื่องดื่มหวานมากขึ้น"
4. กด **30 วัน** ทีเดียวตอนจะเลื่อนลง เพื่อให้เห็นว่ามีข้อมูลยาวกว่านั้น แล้วเลื่อนลงตาราง pattern ต่อเลย

> ⚠️ **ห้ามค้างที่ 7 วัน** — ช่วงนั้นไม่มี insight อุ่นไว้ จะเจอปุ่ม "วิเคราะห์รูปแบบ" ที่กฎเหล็กห้ามกด
> ⚠️ **ที่ 30 วัน marker ย่อเป็นจุด ไม่มีไอคอน** (วันชิดกันเกินไป) — เหตุผลที่อธิบายตอนค้าง 14 วัน · แตะจุดยังเปิด popover เห็นชื่อ disruptor + โน้ตได้ทุกโหมด

### 3. Pattern table — **อยู่ในบท · งบ 30 วิ** · Plan B = **สไลด์ 11 (สำรอง A)**

### 4. AI Coach + guided goal — **อยู่ในบท · งบ 1:30 (ยาวที่สุดในบท ตั้งใจให้ยาว)** · สลับไป**สไลด์ 5** ตอนเทียบสองกิ่ง · Plan B = **สไลด์ 13 (สำรอง C)**

2. เดิน guided flow "ตั้งเป้าสัปดาห์หน้า" (ปุ่มเหนือช่องพิมพ์) — เลือกด้าน → วันยุ่ง → ข้อจำกัด → **ขั้นสุดท้ายยิง Gemini สดเพื่อแนะนำ goal** (ข้อความโค้ชระหว่างทางเป็นบทเขียนไว้ ไม่ยิง)
3. ชี้ว่า goal ผูกตารางจริงของปาล์ม (วันเรียนเช้า จันทร์/พุธ)
4. **Plan B ถ้าโควตาหมด/ช้า:** ขั้นสุดท้าย fallback เป็น goal template อัตโนมัติ (ไม่ crash) — หรือใช้ screenshot guided flow ที่ถ่ายไว้ตอนซ้อม
5. **ห้ามพิมพ์ข้อความแชทใหม่สดนอก guided flow** — เปลืองโควตา + เสี่ยงคำตอบไม่เหมือนซ้อม

### ✂️ 5. Weekly reflection — **ตัดจากรอบบ่าย · ใช้ที่บูธเช้า** · ถ้าถูกถามตอน Q&A เปิด **สไลด์ 12 (สำรอง B)**
1. ไป `/reflection`
2. แบนเนอร์ "สรุปนี้ยังไม่รวมบันทึกล่าสุด" **ตั้งใจให้โชว์** (โผล่ทันทีที่มี check-in ใหม่กว่าสรุปที่ cache ไว้ — เช่นหลังกรอกสดที่บูธ · ระบบเช็คจากบันทึกล่าสุด ไม่ใช่ปฏิทินสัปดาห์) — พูดได้เลยว่า *"ระบบซื่อสัตย์ว่าสรุปนี้ยังไม่รวมวันล่าสุด — เราแยกข้อมูลจากข้อสรุปเสมอ"* · **ห้ามกดปุ่มสร้างสรุปใหม่**
3. โชว์ reflection สัปดาห์ล่าสุด → เลื่อนดูย้อนหลัง 4 สัปดาห์
4. ชี้ **เทียบสัปดาห์ก่อน** แล้ว**อ่านตัวเลขจากจอ อย่าท่องเลขล่วงหน้า** — ตัวเลขคำนวณสดทุกวัน ชุดที่จะเห็นจริงพิมพ์อยู่ท้ายผลรัน `refresh:demo-week` เช้าวันนั้น
   > 🔴 **ห้ามเตรียมบทว่า "ชี้ลูกศรขึ้น"** — ลูกศรขึ้นหรือลงขึ้นกับข้อมูลสัปดาห์นั้น · ชุด 25 ก.ค. ของปาล์มคือ นอน ↑ · ขยับ ↓ · กินครบ ↓ **ลงมากกว่าขึ้น**
   > ถ้าเจอลูกศรลง ให้ใช้เป็นจุดขายแทน: *"สัปดาห์นี้บางตัวลง ระบบก็แสดงตามจริง ไม่ตัดสิน ไม่ลดคะแนนใคร"* — ตรงกับ key message ของโจทย์มากกว่าการหาลูกศรขึ้นมาชี้
5. ย้ำ: ไม่มีคะแนนสุขภาพ ไม่มีคำตำหนิ
