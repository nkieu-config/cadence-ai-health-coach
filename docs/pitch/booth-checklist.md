## 🔴 ทดสอบเครือข่ายอื่น — ทำก่อนวันงาน แล้วทำซ้ำหน้างาน

ประกาศสั่ง: *"ตรวจสอบ demo บนเครือข่ายอื่น **ไม่ใช่เฉพาะเครื่องที่ใช้พัฒนา**"*

แอปเราไม่มีโหมด offline — **เน็ตล่ม = เดโมจบ** นี่คือความเสี่ยงเดี่ยวที่ใหญ่ที่สุดของทั้งงาน

**ก่อนวันงาน:**

- [ ] เปิด `personal-healthcoach.vercel.app` จาก **มือถือที่ปิด wifi ใช้ 4G/5G** → ล็อกอิน → เดิน guided goal 1 รอบจนจบ
- [ ] เปิดจาก **เครื่องที่ไม่ใช่เครื่องที่ใช้พัฒนา** → ทำแบบเดียวกัน
- [ ] ลองบน **เบราว์เซอร์ที่ไม่ใช่ตัวหลัก** (Safari ถ้าปกติใช้ Chrome)

> 📶 **แผนเน็ตหลักคือ hotspot จาก iPhone เข้า Mac ไม่ใช่ wifi ห้อง**
> เน็ตห้องประชุมที่มีคนต่อพร้อมกันทั้งงานเป็นตัวแปรที่เราคุมไม่ได้ · hotspot คุมเองได้ทั้งหมด
> **แต่ยังต้องกดลองสักครั้งก่อนวันงาน** — "แชร์ได้" กับ "ลองแล้วเดินครบทั้งบท" คนละเรื่อง
> ก่อนออกจากบ้าน: **ชาร์จ iPhone ให้เต็ม** และเช็คว่าแพ็กเกจเน็ตเหลือพอทั้งวัน

**หน้างาน ช่วง 10.00 ก่อนเริ่ม:**

- [ ] เปิด hotspot แล้วต่อ Mac → เปิดแอป → เดิน guided goal 1 รอบ
- [ ] ลอง wifi ห้องด้วยเป็นทางสำรอง — ถ้าช้าหรือบล็อก **กลับไป hotspot ทันที อย่านั่งรอ**

> **ทำไมต้องมีบัญชีที่สาม** — ประกาศบอกว่ากรรมการจะ *"ทดลองผลงาน"* · ถ้าเขาล็อกอินบัญชีเดียวกับที่เราเดโมบนจอ **สิ่งที่เขากดจะเปลี่ยนจอเราทันที** และโควตาแชท 5 ข้อความ/วันจะโดนกรรมการใช้หมดตั้งแต่คนแรก
>
> **สร้างและทดสอบบน production แล้วเมื่อ 29 ก.ค.** — `judge@example.com` / `judgecadence123` · ล็อกอินบนโปรไฟล์ iPhone ผ่าน · dashboard · coach · reflection ขึ้นครบ · ไม่มี console error
> รันคำสั่งข้างบนซ้ำเช้าวันจริงเพื่ออัปเดตวันที่ (ข้อมูลผูกกับวันปัจจุบัน) — **ไม่ต้องรัน `npm run seed` ซ้ำ บัญชีมีแล้ว**

> ✅ **ถ้าขึ้น `⚠️ พบคำที่ต้องอ่านยืนยัน: ล้มเหลว` ไม่ต้องตกใจ** — ตรวจครบทั้ง 3 บัญชีเมื่อ 29 ก.ค. แล้ว
> ทุกบัญชีเป็นวลีเดียวกันคือ **"ล้มเหลวยาก"** (ก้าวเล็ก ๆ ที่ล้มเหลวยาก) ซึ่งตรงข้ามกับการตัดสินผู้ใช้
> ตัวจับเป็น substring match จึงติดเอง · **แต่ถ้าขึ้นคำอื่นที่ไม่ใช่ "ล้มเหลว" ให้เปิด `/coach` อ่านทั้งประโยคก่อน**

> 🔴 หลังรันเสร็จ **เปิด `/reflection` แล้วหาคำว่า "สิ่งรบกวนตาราง" กับ "วันพิเศษ" — ต้องไม่เจอสักคำ**
> ถ้าเจอแปลว่าสรุปที่ขึ้นจอยังเป็นฉบับก่อนแก้บั๊ก (ต้องเป็น "ปัจจัยรบกวน" คำเดียว) · ตรวจ 28 ก.ค. เคยเจอค้าง 8 จุด — `refresh` สร้างใหม่ให้ แต่**ต้องยืนยันด้วยตาทุกครั้ง**
